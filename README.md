## 📄 Activating the Resume Download Button
To activate the **Download Resume** buttons in the header, hero section, and resume banner:
1. Export your resume as a PDF.
2. Rename it to `resume.pdf`.
3. Place it inside this folder (`c:\Users\anush\Desktop\portpholio\resume.pdf`).
4. That's it! The download links are already wired to download `resume.pdf`.
